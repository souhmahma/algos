# Algorithmes en Python

Programme interactif en terminal pour tester des algorithmes classiques. On choisit un algorithme dans le menu, et le programme affiche un exemple et sa complexité.

## 🚀 Utilisation

```bash
python algos.py
```

Python 3.6+ suffit, aucune dépendance.

## 📚 Algorithmes

- **Tris** : à bulles, insertion, sélection, fusion, rapide
- **Recherche** : dichotomique (récursive et itérative)
- **Tableaux** : doublons, occurrences, somme de deux valeurs, Kadane, fenêtre glissante
- **Maths** : Newton, Fibonacci, rendu de monnaie
- **Pile** : vérification des parenthèses
- **Graphes** : BFS, DFS, Dijkstra
- **Listes chaînées** : détection de cycle, inversion
- **Arbre binaire de recherche** : recherche, insertion
